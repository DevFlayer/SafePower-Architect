SafePower Architect
SafePower Architect is a C++ command-line tool designed for Computer Engineering students and PC builders to calculate power supply (PSU) requirements.

Key Features:
Hardware Selection: Choose between high-end GPUs to determine base power draw.

Engineering Margin: Automatically calculates a 30% safety margin for optimal efficiency.

Automated Diagnostic: Categorizes PSU health into Safe, Warning, or Critical based on real-world power consumption logic.
